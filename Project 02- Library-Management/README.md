# Library Management System

## Introduction
The Library Management System is a Python-based project that helps manage books in a library. It allows users to add, search, issue, return, and display books.

## Features
- Add new books
- Search for books
- Issue books
- Return books
- Display available books
- Save book records in a text file

## Technologies Used
- Python
- File Handling
- Loops and Conditional Statements
- Functions

## Files Included
- `library_management.py` — Python source code
- `library.txt` — Book records
- `screenshot1.png` — Console output screenshot
- `screenshot2.png` — Console output screenshot

## How to Run
1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   `py library_management.py`

5. Follow the menu options displayed in the terminal.

## Conclusion
This project demonstrates how Python can be used to manage library book records through a simple menu-driven program and file handling.
