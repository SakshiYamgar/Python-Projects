# Bank Account Management System

## Introduction

The Bank Account Management System is a Python-based project designed to perform basic banking operations. It allows users to create accounts, deposit money, withdraw money, check balances, and view transaction history.

## Features

- Create a new bank account
- Deposit money into an account
- Withdraw money from an account
- Check account balance
- Display transaction history
- Save account details in a text file

## Technologies Used

- Python
- Dictionaries
- Functions
- Loops and Conditional Statements
- File Handling

## Files Included

- `bank_management.py` – Python source code
- `bank_data.txt` – Stores account details and transaction records
- `README.md` – Project description and instructions
- `screenshot3.png` – Console output screenshot
- `screenshot4.png` – Console output screenshot

## How to Run

1. Install Python on your computer.

2. Download or clone this project repository.

3. Open the project folder in VS Code.

4. Open the terminal.

5. Run the following command:

   `py bank_management.py`

6. Select an option from the menu and follow the instructions.

## Conclusion

This project demonstrates the use of Python functions, dictionaries, loops, and file handling to create a simple menu-driven Bank Account Management System.
