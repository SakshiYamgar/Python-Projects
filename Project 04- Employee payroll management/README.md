# Employee Payroll System

## Introduction
The Employee Payroll System is a Python-based project used to manage employee details and calculate salaries. It allows users to add employees, calculate gross and net salaries, generate payslips, search employee records, and save payroll data in a text file.

## Features
- Add new employee details
- Calculate gross salary and net salary
- Generate employee payslips
- Search employees using Employee ID
- Save payroll data in a text file
- Display a menu-driven interface

## Salary Calculation
- **Gross Salary** = Basic Salary + Allowances
- **Net Salary** = Gross Salary - Deductions

## Technologies Used
- Python
- Dictionaries
- Functions
- Loops and Conditional Statements
- File Handling

- `employee_payroll.py` – Python source code

## How to Run
1. Install Python on your computer.
2. Download or clone this project repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   `py employee_payroll.py`

6. Select an option from the menu and follow the instructions.

## Conclusion
This project demonstrates how Python can be used to manage employee information, calculate salaries, generate payslips, and store payroll records using file handling.
