# Student Management System

## Introduction
The Student Management System is a simple Python project designed to manage student records. It allows the user to add, display, search, update and delete student details.

## Objectives
- To store student information.
- To manage student records easily.
- To calculate the average marks of a student.
- To save student records in a text file.

## Features
1. Add Student
2. Display Students
3. Search Student
4. Update Student Records
5. Delete Student Records
6. Calculate Average Marks
7. Save Records
8. Exit the Program

## Technologies Used
- Programming Language: Python
- Data Storage: Text File
- Platform: GitHub

## How to Run
1. Download or clone this repository to your computer.
2. Make sure Python is installed.
3. Open a terminal in the project folder.
4. Run the following command:

   `python student_management.py`

## Files Included
- `student_management.py` — Contains the Python source code.
- `students.txt` — Contains sample student records.
- `README.md` — Contains project details and instructions.
